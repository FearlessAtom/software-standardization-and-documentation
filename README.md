Практична робота [STUDENT_DOCS](./STUDENT_DOCS.pdf) включає в себе створення документу, схожого до дипломного проєкту.

Документ повинен включати:
- Вступ (мета, завдання, предмет, обʼєкт, актуальність, практичне значення)
- Умовні позначення (якщо є)
- Перший розділ. Опис технологічного стеку 1 сторінка.
- Висновки
- Посилання на літературні джерела.
